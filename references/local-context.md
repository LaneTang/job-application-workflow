# 用户资料与工作区定位

使用用户指定的求职工作区，不把 skill 安装目录当作申请资料目录。

- 最新资料：工作区 `profile/profile.md`；初次使用可从仓库 `examples/profile.example.md` 创建。
- 简历：工作区 `profile/`，采用用户指定并确认的版本。
- 申请账本：工作区 `applications/applications.json`；可读索引：`applications/README.md`。
- 可选设计文档与历史交接：仅使用用户实际提供的位置；当前用户指令及指定设计优先，历史状态须核对。

不把联系方式、住址、身份文件、简历副本或申请记录存入 skill。运行时读取 profile 的实际身份与实习定位，结合完整题目判断 sponsorship；不预设签证类型或固定答案。

恢复申请时读取现有账本并核对页面、提交凭据或用户确认。历史状态不是通用 skill 的永久事实。查看本地邮件时只保存必要的来源与摘要，不保存登录令牌或无关正文。
